# 모의투자 기록지

가상자금 1,000만 원을 기준으로 첫 배분안을 만들고, 이후에는 원래 생각을 남겨둔 채 주차별 기록을 추가합니다. 종이나 개인 메모에 작성하면 됩니다.

| --- | --- |

| 사용한 가격의 출처 또는 가정 | |

| 자산 | 기준 단가 | 수량 | 배분 금액 | 선택 이유 |
| --- | ---: | ---: | ---: | --- |
| | | | | |
| | | | | |
| 현금 | — | — | | |
| 합계 | — | — | 10,000,000원 | |

- 근거와 출처:
- 손실이 날 수 있는 이유:
- 다음에 확인할 질문:
- 판단을 바꿀 조건:

금액은 단가 × 수량으로 계산하고 나머지는 현금에 넣습니다. 금액을 배분하지 않은 자산의 행은 비워도 됩니다.

## 작성 예시

가격과 기업은 가상이며, 예시 계산에서는 수수료·세금·배당을 생략합니다.

| 자산 | 기준 단가 | 수량 | 배분 금액 | 선택 이유 |
| --- | ---: | ---: | ---: | --- |
| 가상 기업 A | 10,000원 | 300주 | 3,000,000원 | 아는 제품의 매출 비중을 확인해 보고 싶다. |
| 현금 | — | — | 7,000,000원 | 같은 업종의 다른 기업도 조사할 시간을 둔다. |
| 합계 | — | — | 10,000,000원 | |

- 근거: 주요 제품과 고객을 설명할 수 있다.
- 손실 가능성: 원재료 가격이 오르면 제품이 잘 팔려도 이익이 줄 수 있다.
- 확인할 질문: 최근 보고서에서 해당 제품의 매출 비중과 비용 추이를 확인할 수 있는가?
- 판단을 바꿀 조건: 조사한 제품이 전체 사업에서 차지하는 비중이 예상보다 작다면 기업을 고른 이유를 다시 검토한다.

## 주차별 갱신

배분 비중을 바꾸기 전에 같은 기준 시점의 가격으로 기존 보유분을 평가합니다. 평가액은 보유 수량 × 해당 시점 가격을 자산별로 합산하고 남은 현금을 더해 구합니다.

| 주차 | 평가액 | 새로 확인한 사실과 출처 | 유지 또는 변경한 판단과 이유 |
