# 주차별 활동지

표를 개인 메모에 복사하거나 모의투자 기록지에 판단 근거를 남깁니다. 공식 자료를 읽었다면 문서 제목, 링크, 기준일을 함께 적습니다. 작성한 기록은 8주차에 다시 사용합니다.
