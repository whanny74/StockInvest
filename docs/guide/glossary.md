# 주식투자 용어집

수업에서 다시 확인하고 싶은 말은 여기서 찾아봅니다. 각 장의 풀이 예제에서는 용어를 여러 개 연결해서 사용합니다.

## 시장과 주문 · 1~2주차

| 용어 | 뜻 |
| --- | --- |
| 주식·주주·지분 | 주식은 회사 소유권을 나눈 단위이고 주주는 주식 보유자다. 같은 종류의 주식만 있는 단순한 예에서 지분율은 내 주식 수를 전체 주식 수로 나눈 비율이다. |
| 신주 발행·기존 주식 거래 | 회사가 새 주식을 발행해 팔면 자금을 조달할 수 있다. 기존 주식이 투자자 사이에서 거래될 때 매수 대금은 주식을 판 쪽에 간다. |
| 상장·거래소·증권사 | 상장은 주식을 거래소에서 거래할 수 있게 하는 절차다. 거래소는 시장을 운영하며 증권사는 고객의 주문을 받아 거래를 중개한다. |
| 주가·시가총액 | 주가는 한 주의 시장가격이다. 발행주식이 한 종류인 예에서 시가총액은 주가 × 주식 수다. |
| 배당 | 회사가 배당을 결정했을 때 권리가 있는 주주에게 돌려주는 돈 등이다. 배당 여부와 금액은 달라질 수 있다. |
| 호가·스프레드 | 호가는 사고팔겠다고 제시한 가격이다. 최우선 매수 호가와 최우선 매도 호가의 차이를 스프레드라고 한다. |
| 시장가·지정가 | 시장가는 가격을 지정하지 않는 주문이다. 지정가는 주문에 가격을 정하는 방식으로, 매수 주문은 지정 가격 이하거나 매도 주문은 지정 가격 이상에서 체결될 수 있다. 체결 자체는 보장되지 않는다. |
| 접수·체결·미체결·부분체결 | 접수는 주문이 받아들여진 상태, 체결은 거래가 성립한 상태다. 주문 전부가 거래되지 않으면 미체결 수량이 남으며, 일부만 거래된 상태를 부분체결이라 한다. |
| 평균 체결가 | 여러 가격에 거래된 경우 전체 체결 대금을 전체 체결 수량으로 나눈 값이다. |
| 평가손익·실현손익 | 평가손익은 보유 중인 자산의 평가액과 원가 차이다. 실현손익은 팔아서 확정된 손익이다. 각 계산에 수수료 등이 포함됐는지 확인한다. |
| 수익률·복리·손실 회복률 | 수익률은 기준금액 대비 손익의 비율이다. 여러 기간 수익률은 각 기간의 변동 배율을 곱해 구한다. 손실 회복률은 원금까지 부족한 금액을 하락 후 자산가치로 나눈다. |

## 기업, 재무제표, 가격 · 3~5주차

| 용어 | 뜻 |
| --- | --- |
| 사업모델·경쟁력 | 어떤 고객에게 무엇을 팔아 매출을 만들고 어떤 비용을 내는지 보는 틀이다. 경쟁력은 고객이 다른 회사 대신 그 회사를 선택할 이유에 대한 판단이다. 확인할 근거를 함께 적는다. |
| 매출·영업이익·순이익 | 매출은 사업에서 인식한 판매액 등이다. 영업이익은 본업의 비용을 반영한 이익이고, 순이익은 이자·세금 등 다른 항목도 반영한 결과다. |
| 매출 성장률·영업이익률 | 매출 성장률은 (당기 매출 − 전기 매출) ÷ 전기 매출이다. 영업이익률은 영업이익 ÷ 같은 기간 매출이다. 백분율은 각각 100을 곱한다. |
| 공시·사업보고서 | 공시는 기업이 외부에 공식적으로 알리는 문서다. 사업보고서는 일정 사업연도의 사업 내용과 재무정보 등을 담은 정기공시다. |
| 연결·별도 | 연결은 지배기업과 연결 대상 종속기업을 함께 보고, 별도는 해당 법인 자체를 중심으로 표시한다. 서로 다른 기준의 값을 직접 비교할 때는 주의한다. |
| 재무상태표·손익계산서·현금흐름표 | 특정 시점의 자산·부채·자본, 일정 기간의 이익, 일정 기간의 현금 이동을 각각 보여준다. |
| 매출채권·영업활동현금흐름 | 매출채권은 판매 등으로 아직 받지 못한 돈이다. 영업활동현금흐름은 영업에서 들어오고 나간 현금 흐름이다. |
| EPS·PER | EPS는 주당순이익이다. PER은 주가 ÷ EPS다. 비교할 때 주가 기준일, 이익 기간, 실적 또는 전망 여부, 일회성 항목을 확인한다. |
| 투자 가설·시나리오 | 가설은 근거를 바탕으로 세운 잠정 판단이다. 시나리오는 가정이 달라질 때 어떤 결과가 나오는지 여러 경우를 놓고 검토하는 방법이다. |

## 배분, 실전, 복기 · 6~8주차

| 용어 | 뜻 |
| --- | --- |
| 지수·ETF | 지수는 일정 기준으로 묶은 시장이나 자산의 움직임을 나타내는 숫자다. ETF는 거래소에서 거래되는 펀드로, 지수를 추종하는 유형 등이 있다. |
| 자산배분·분산투자 | 자산배분은 주식이나 현금 등 자산별 비중을 정하는 일이다. 분산투자는 여러 회사·업종·자산으로 나눠 특정 위험의 영향을 줄이는 접근이다. |
| 종목 중복·집중 위험 | 같은 기업을 개별 주식과 ETF 양쪽에서 보유할 수 있다. 특정 기업이나 업종에 대한 실제 비중이 크면 해당 기업이나 업종의 변화가 전체 자산에 더 큰 영향을 줄 수 있다. |
| 리밸런싱 | 가격 변동으로 달라진 실제 비중을 정해둔 목표 비중에 맞추는 일이다. |
| 주문 가능 금액·취소 | 증권사 화면에서 새 주문에 사용할 수 있다고 표시하는 금액과, 남은 미체결 주문을 거둬들이는 절차다. 이미 성립한 거래와 취소가 완료된 수량을 구분한다. |
| FOMO·확증편향 | FOMO는 기회를 놓칠 것 같아 서두르는 심리다. 확증편향은 자신의 판단에 유리한 정보만 찾거나 더 믿는 경향이다. |
| 투자 기간·손실 한도·재검토 조건 | 사용 목적에 맞춰 돈을 투자해 둘 기간과 감당 가능한 손실 범위를 생각한다. 어느 자료나 사실이 바뀌면 처음 결정을 다시 살펴볼지도 함께 정한다. |

## 심화 읽을거리 { #advanced }

- **PBR(주가순자산비율)** = 주가 ÷ 주당순자산. 장부에 적힌 자산의 구성이 다르면 기업끼리 비교할 때 의미도 달라질 수 있다.
- **ROE(자기자본이익률)**은 자기자본 대비 순이익을 보는 지표다. 평균 자기자본을 사용했는지와 이익 산출 범위를 확인한다. 부채가 늘어난 상황에서도 수치가 높아질 수 있어서 재무상태표를 함께 본다.
- **배당수익률**은 선택한 기간의 주당배당금을 기준 주가로 나눈 비율이다. 과거 배당금을 썼다면 앞으로도 유지된다는 뜻은 아니다.
- **거래일과 결제일**은 구분한다. 체결은 거래가 성립한 상태이고 결제는 그 거래에 따른 돈과 증권이 정산되는 단계다. 실제 일정, 수수료, 세금은 시장·상품·계좌에 따라 달라질 수 있으므로 수업 때 사용할 증권사의 공식 안내에서 확인한다.
