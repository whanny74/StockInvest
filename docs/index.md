# 처음 배우는 주식투자

한 주에 60분씩, 기업이 돈을 버는 방식부터 내가 지킬 투자 원칙까지 배웁니다. 기업 공시를 읽고 숫자를 계산한 뒤, 그 근거로 판단을 설명합니다.

[모의투자 기록지](activities/portfolio-template.md){ .md-button }

## 함께 공부하는 방법

- 매주 복습 5분, 개념 15분, 실습 25분, 토론 10분, 퀴즈 5분으로 진행합니다.
- 1주차에 가상자금 1,000만 원으로 첫 배분안을 기록합니다. 4~5주차에 공시와 가격 지표로 근거를 점검하고, 6주차에 분산 원칙을 적용합니다.
- 8주차에는 처음 기록과 마지막 기록을 비교합니다. 평가 기준은 근거를 확인하고 판단을 바꾼 이유를 설명할 수 있는지입니다.
