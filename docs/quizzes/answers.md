## 2주차 · 수익률과 손실 { #week02 }

[2주차 수업](../weeks/week02-return-and-risk.md)

1. **−10%.** (18,000 − 20,000) ÷ 20,000 × 100.
2. **손익 19,000원, 수익률 약 18.91%.** 처음 지급한 100,500원과 매도 후 받은 119,500원의 차이다. 주가만 비교한 수익률은 20%다.
3. **−3%.** A는 30만 원 줄고 현금은 그대로다. 전체는 1,000만 원에서 970만 원이 된다.
4. **25%.** 회복에 필요한 20만 원을 현재 금액 80만 원으로 나눈다. 80만 원에서 20%만 오르면 96만 원이다.
5. **비율을 적용하는 기준 금액이 달라진다.** 100 × 1.1 × 0.9 = 99다.

## 3주차 · 기업의 사업과 경쟁력 { #week03 }

[3주차 수업](../weeks/week03-good-company.md)

1. **14%.** 140 ÷ 1,000 × 100.
2. **약 33.3%.** (800 − 600) ÷ 600 × 100이다. A의 매출 증가율은 약 11.1%다.
3. **매출이 영업이익보다 더 빠르게 늘었다.** B의 영업이익률은 전년 10%에서 당년 8%가 됐다.
4. **그 고객의 주문이나 계약 조건이 바뀌면 매출이 얼마나 영향을 받을까?** 장기계약 여부와 다른 고객을 확보할 가능성을 살펴볼 수 있다.
5. **기간과 연결·별도 범위.** 숫자가 같은 단위인지도 확인한다.

## 4주차 · 사업보고서 읽기 { #week04 }

[4주차 수업](../weeks/week04-financial-statements.md)

1. **재무상태표.** 특정 결산일의 자산, 부채, 자본을 보여준다.
2. **손익계산서.** 일정 기간 동안의 매출과 이익을 보여준다.
3. **40억 원 감소.** 같은 기간에 영업이익은 20억 원 늘고 매출채권은 45억 원 늘었다.
4. **원인 후보로 기록한다.** 회수 전 매출이 늘었을 수 있다. 현금흐름표 조정 항목과 관련 주석에서 재고, 매입채무 등의 변화도 확인해야 한다.
5. **회계 기간, 표시 단위, 연결·별도 기준.** 정정 여부와 링크도 함께 기록하면 확인하기 쉽다.

## 5주차 · 기업과 가격 평가 { #week05 }

[5주차 수업](../weeks/week05-valuation.md)

1. **20배.** 10,000원 ÷ 500원.
2. **보고값 10배, 조정 가정 20배.** 100,000 ÷ 10,000 = 10. 일회성 효과를 빼면 EPS는 5,000원이고 100,000 ÷ 5,000 = 20이다.
3. **25배.** 10,000 ÷ 400이다. EPS 625원 가정에서는 16배다.
4. **이익이 음수이면 양의 이익 몇 배를 지불한다는 해석을 적용하기 어렵다.** 손실의 원인과 향후 이익 가정이 필요하다.
5. **주가 기준일과 EPS 실적 기간.** 전망 EPS를 썼다면 전망 대상 기간도 표시한다.

## 6주차 · ETF와 분산투자 { #week06 }

[6주차 수업](../weeks/week06-portfolio.md)

1. **18%.** ETF X 30% × 40% = 12%, ETF Y 30% × 20% = 6%이며 직접 보유는 0%다.
2. **첫 배분 −7.5%, 새 배분 −4.5%.** 각각 A 노출 30%, 18%에 −25%를 곱한다. 나머지 가격은 그대로라는 수업 가정이다.
3. **같은 기업이나 업종이 두 ETF에 함께 들어 있을 수 있다.** 상위 보유 종목과 비중을 함께 확인한다.
4. **리밸런싱.** 실제 비중을 기존 목표 60%로 맞추는 작업이다.
5. **예를 들어 시장 전체가 하락할 때 여러 ETF가 같이 손실을 낼 가능성.** 실습의 새 배분은 A 집중을 줄이는 한편 주식 전체 노출은 30%에서 60%로 늘린다.

## 7주차 · 뉴스와 투자심리 { #week07 }

[7주차 수업](../weeks/week07-news-and-psychology.md)

1. **100억 원, 2년.** 공급 일정은 주문에 따라 달라질 수 있다.
2. **계약 금액은 2년 전체에 해당하며 올해 매출 인식액이 주어지지 않았다.** 다른 거래에서 매출이 줄 수도 있다.
3. **확증편향.** 반대 근거를 찾아보는 행동을 판단 과정에 넣는다.
4. **예를 들어 원금·고수익 보장, 즉시 송금 압박, 개인 계좌 송금 요구.** 당장 송금할 이유가 있는지 상대의 설명을 그대로 받아들이지 않고 독립적으로 확인한다.
5. **확인되지 않음으로 기록한다.** 회사 공식 공시나 IR에서 원문을 찾아보고 확인 전에는 주장을 근거로 사용하지 않는다.

## 8주차 · 나의 투자 원칙 { #week08 }

[8주차 수업](../weeks/week08-my-investment-rules.md)

1. **사용 시점과 금액.** 다른 자금으로 대신할 수 있는지도 확인하고 정해진 지출을 따로 기록한다.
2. **수익률만으로는 판단 근거의 질을 평가하기 어렵다.** 근거를 찾아 기록했는지, 불리한 정보가 생겼을 때 판단을 검토했는지 살핀다.
3. **투자 가설의 근거였던 사실이 바뀌었는지 확인한다.** 고객 주문이나 이익의 지속성을 보고 판단했다면 관련 공시와 주석부터 찾아본다.
4. **직접 보유 비중에 ETF별 전체 비중 × ETF 내 기업 비중을 합산한다.** 구성 종목 기준일을 맞춘다.
5. **예시** — “최대 고객과의 계약 종료가 공시되면 관련 매출과 대체 고객 자료를 확인할 때까지 추가 주문을 보류한다.” 상황, 자료, 행동이 들어가면 된다.
